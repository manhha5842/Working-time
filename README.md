## How it works

```text
WakaTime API
    ↓
GitHub Actions (daily)
    ↓
data/YYYY/MM/YYYY-MM-DD.json
    ↓
scripts/generate_readme.py
    ↓

```

The workflow refreshes the most recent **7 days** on every run, so a missed or delayed run can recover automatically.
